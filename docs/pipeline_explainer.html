How I find the cuts

audio

Silences

I use FFmpeg to find short silences, including pauses within adverts.

schedule

Match the schedule

I keep a break if every scheduled join matches a silence. I fix the recording start when two full matches give start times within five seconds of each other. Otherwise, I align each break separately.

picture

Find the first frame

Start at the midpoint of the silence. After correcting the video offset, move the cut to the first sharp picture change near the silence if there is one.

audio

Silence guard

If the cut lands more than 80 ms after the silence ends, move it back to the midpoint.

Where the last clip ends

Open issue · v17
