Advert segmentation pipeline

The pipeline cuts single adverts out of continuous UK television recordings from the BFI National Archive, using the industry metadata as a guide. This page reports the latest full run (15 October 2026) and traces how the pipeline got there from the first full run in September. How the pipeline works is shown in the pipeline explainer.

1 · The material

The recordings are continuous, and the metadata keeps a different clock

DeliveryThe first BFI delivery, selected so that every advert identifier appears at least once1
RecordingA continuous broadcast, tens of minutes to three hours, programmes and breaks in turn1,670
BreakListed in the metadata with clock times, never with a position in the file11,254
RecordOne row per advert broadcast: time, place in break, brand, identifier97,213
ClipOne advert cut out of the recording, with one row in the processing log28,632adverts cut

The metadata gives clock times, while a file counts from zero, and nothing records when a recording began. The two clocks have to be matched before the metadata can be used, and the metadata gives times to the second, while a cut has to be placed to the frame (25 a second).

The identifier states a length: its last three digits are the advert's length in seconds. Where an advert is followed by another in its break, the next one starts exactly that many seconds later in 99.6% of 62,001 cases. Every clip can therefore be checked against a length known in advance.

Because the recordings were selected to cover every identifier, channel and time of day are always taken from the full broadcast history in the metadata, not from the clip.

Each identifier is one advert

Ten- and thirty-second versions under the same brand carry different identifiers and are counted as different adverts.

Placeholder rows are removed

Addressable advertising is sold per household. Three placeholder identifiers mark these slots in 25,975 of the 97,213 records (about 27%); a real advert at the same start time keeps the boundary.

Only what the metadata lists is cut

A sponsor's advert shown just before a break has no record, so it is not in the corpus.

4 · Coverage

Three quarters of the unique adverts were obtained

18,890 unique adverts in the metadata · latest full run
14,189 obtained
3,103 missing, aired once
1,598 other

Two thirds of the adverts still missing appear only once in the delivery, so for them a lost slot is a lost advert.

The slot was never in the file

The metadata lists breaks that are not in the recording: 9,826 of 54,515 slots. Of the 44,689 slots inside the recordings, 28,632 are kept (64.1%).

A boundary found no silence

The strict rule drops a break if any one boundary misses; 545 breaks were lost to a single missing boundary.

The break sat in the wrong place

171 breaks did not agree with the start of the recording and were dropped.

A loss that falls unevenly changes the shape of the corpus, so retention is reported by year, advert length and channel before any distribution is compared.
